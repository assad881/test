1. ما هو المساعد؟

المساعد هو إعداد لـ Claude Code يجعله يعمل كـإحصائي أول ومستشار بيانات ومساعد تنفيذي لك، يعرف طبيعة عملك في المديرية العامة للخدمات الصحية بمحافظة الظاهرة ومشروع AsaadStat، ويلتزم بمعاييرك في التقرير الإحصائي.

ملف التعريف
CLAUDE.md — يُحمَّل تلقائياً: هويتك، أسلوبك، ومعايير التقرير.
الأوامر الجاهزة
13 أمراً تبدأ بـ / لمهامك المتكررة.
محرك التحليل الآلي
Excel + خطة ← تقرير Word وجداول وSPSS syntax.
قاعدة المعرفة
معايير التقرير، دليل اختيار الاختبار، الأسعار، المهام.

معايير يلتزم بها في كل المخرجات

  • قيمة p بثلاث خانات عشرية، و p < 0.001 عند الأصغر — لا يكتب أبداً p = 0.000.
  • كل اختبار مع قيمته ودرجات الحرية وحجم الأثر (d, r, η², Cramér's V, AOR مع 95% CI).
  • الانحدار اللوجستي: OR غير المعدّلة والمعدّلة، Nagelkerke، Hosmer–Lemeshow، وفحص EPV ≥ 10.
  • لا يخترع أرقاماً: إن غابت المخرجات يطلبها أو يحسبها بالمحرك.
  • لا يستخدم لغة سببية في الدراسات المقطعية.

ما يحسبه محرك التحليل تلقائياً

التكرارات والنسب · ألفا كرونباخ وα عند حذف البند · درجات ومستويات KAP (Bloom) · اختيار الاختبار حسب التوزيع والتجانس (t / Welch / Mann–Whitney / ANOVA / Welch ANOVA / Kruskal–Wallis) مع حجم الأثر · مربع كاي/فيشر مع Cramér's V · سبيرمان · الانحدار اللوجستي · ROC.

2. التشغيل لأول مرة

  1. افتح Claude Code على المستودع.
    من المتصفح: claude.ai/code ثم اختر المستودع assad881/test. أو من جهازك: 
    git clone https://github.com/assad881/test.git
cd test
claude
  2. ثبّت المكتبات مرة واحدة (تحتاجها للتحليل الآلي): 
    pip install pandas scipy statsmodels openpyxl python-docx tabulate matplotlib
  3. جرّب المثال التجريبي للتأكد أن كل شيء يعمل: 
    python3 assistant/engine/auto_analysis.py assistant/examples/kap_plan.json
    ستجد المخرجات في assistant/output/.
  4. خصّص الإعدادات: أدخل أسعارك في assistant/knowledge/pricing.md وأضف مهامك في assistant/TASKS.md.
💡 لا تحتاج تذكير Claude بمن أنت في كل جلسة — ملف CLAUDE.md يُقرأ تلقائياً عند فتح المستودع. يمكنك الكتابة بالعربية أو الإنجليزية، وسيرد بنفس لغتك.

4. التحليل الآلي الكامل خطوة بخطوة

أ. جهّز ملف البيانات

  • ملف Excel أو CSV: صف لكل مشارك وعمود لكل متغير، والصف الأول أسماء المتغيرات.
  • أسماء أعمدة قصيرة بلا مسافات: K1, K2, A1, gender, age_group.
  • البنود مرمّزة رقمياً: معرفة (1 صحيح / 0 خطأ)، ليكرت (1–5).
  • احذف الأسماء والأرقام المدنية وأي بيانات تعريفية قبل التحليل.

ب. ضعه في مجلد العميل

assistant/clients/nursing_kap/data.xlsx
assistant/clients/nursing_kap/questionnaire.docx

ج. شغّل الأمر

/analyze assistant/clients/nursing_kap/data.xlsx assistant/clients/nursing_kap/questionnaire.docx

د. ماذا يحدث؟

  1. فحص جودة البيانات: القيم المفقودة، القيم خارج المدى، التكرار — ويعرض لك جدولاً بالمشكلات.
  2. بناء الخطة: يقرأ الاستبيان ويحدد المحاور والبنود العكسية ونقاط القطع والمتغيرات المنبئة.
  3. عرض الخطة عليك: جدول (الهدف ← المتغيرات ← الاختبار) مع الافتراضات.
  4. التشغيل والمراجعة: يراجع النتائج نقدياً (الافتراضات، الخلايا القليلة، EPV) ويعيد التشغيل إن لزم.
  5. التسليم: قائمة الملفات و5–7 نتائج رئيسية والمحددات.

5. ملف خطة التحليل plan.json

الخطة تخبر المحرك ماذا يحلل. عادةً يكتبها Claude لك عبر /analyze، لكن من المفيد فهم حقولها لتعديلها. انطلق من القالب assistant/templates/analysis_plan_template.json.

الحقلالوظيفة
project, titleاسم المشروع (يُستخدم في أسماء الملفات) وعنوان التقرير
dataمسار ملف البيانات نسبةً لمكان الخطة
demographicsالمتغيرات الديموغرافية لجدول الخصائص
scalesالمحاور: البنود، الحد الأدنى والأعلى، البنود العكسية، نقاط القطع (افتراضياً 60 و80٪)، أسماء المستويات
group_comparisonsمقارنة الدرجات حسب الخصائص (يختار الاختبار آلياً)
associationsمربع كاي بين الخصائص ومستوى المحور
correlationsمتغيرات مصفوفة ارتباط سبيرمان
logisticالمتغير التابع، قيمة الحدث، المتغيرات المنبئة، الفئات المرجعية
rocتحليل ROC (انظر القسم 7)
languages["en"] أو ["ar"] أو ["en","ar"]
recodeتحويل نصوص إلى أرقام، مثل صحيح/خطأ ← 1/0

مثال لمحور

"scales": {
  "Attitude": {
    "items": ["A1","A2","A3","A4","A5","A6","A7","A8"],
    "item_min": 1, "item_max": 5,
    "reverse_items": ["A8"],
    "cutoffs_pct": [60, 80],
    "labels": ["Negative", "Neutral", "Positive"]
  }
}

ينشئ المحرك تلقائياً: Attitude_score وAttitude_pct وAttitude_level وAttitude_adequate (كافٍ/غير كافٍ عند نقطة القطع الأولى) — ويمكن استخدامها في المقارنات والانحدار وROC.

⚠ نقاط قطع Bloom (60/80٪) افتراضية — تأكد أنها تناسب أداة دراستك والأدبيات قبل النشر.

6. التقارير العربية

للحصول على تقرير عربي، اطلب ذلك صراحةً من Claude («أريد التقرير بالعربي»)، أو أضف للخطة:

"languages": ["en", "ar"],
"title_ar": "معارف واتجاهات وممارسات الممرضين تجاه العناية بالقدم السكرية",
"var_labels": {
  "gender":    {"en": "Gender",      "ar": "الجنس"},
  "education": {"en": "Education",   "ar": "المؤهل العلمي"},
  "Knowledge_score": {"en": "Knowledge score", "ar": "درجة المعرفة"}
},
"value_labels_ar": {"Bachelor": "بكالوريوس", "Hospital": "مستشفى"}

أو من سطر الأوامر مباشرة:

python3 assistant/engine/auto_analysis.py plan.json --lang ar
python3 assistant/engine/auto_analysis.py plan.json --lang en,ar

خصائص التقرير العربي

  • صفحة وجداول وفقرات من اليمين لليسار، والجداول العريضة في صفحات أفقية.
  • العناوين والتفسير والملاحظات وأسماء الاختبارات بالعربية.
  • الرموز الإحصائية والأرقام بالحروف اللاتينية (المعتاد في التقارير الخليجية).
  • فئات شائعة مترجمة مسبقاً: ذكر/أنثى، نعم/لا، جيد/متوسط/ضعيف، كافٍ/غير كافٍ، عُماني/غير عُماني.
💡 كل النصوص العربية في ملف واحد: assistant/engine/i18n.py. لتغيير أي صياغة لتناسب أسلوب المديرية، اطلب من Claude: «عدّل صياغة فقرة الانحدار في التقرير العربي إلى …».
⚠ أسماء المنحنيات داخل صورة ROC تبقى بالإنجليزية (عنوان الشكل في التقرير بالعربية).

7. تحليل منحنى ROC

يُستخدم لتقييم قدرة مؤشر أو درجة (مثل HbA1c أو درجة مقياس) على التمييز بين حالتين (مريض/سليم، كافٍ/غير كافٍ).

الطريقة السريعة

/roc assistant/clients/study/data.xlsx diabetes_status HbA1c FBS

في الخطة

"roc": {
  "outcome": "Practice_adequate",
  "event": "Adequate",
  "markers": ["Knowledge_score", "Attitude_score"],
  "direction": {"Attitude_score": "higher"},
  "include_logistic_model": true
}
الحقلالمعنى
outcome / eventالمعيار المرجعي وقيمة الحالة الموجبة
markersمؤشر واحد أو أكثر للمقارنة
direction"higher" إن كانت القيم الأعلى تدل على الحالة (افتراضي)، أو "lower"
include_logistic_modelإضافة منحنى للاحتمال المتنبأ من نموذج الانحدار

ما ستحصل عليه

  • AUC مع فترة ثقة 95% (DeLong) وقيمة p، وتفسيرها (مقبولة / ممتازة / ممتازة جداً).
  • نقطة القطع المثلى بمؤشر Youden مع الحساسية والنوعية (فترات Wilson).
  • PPV وNPV (تعتمدان على نسبة الانتشار) وLR+ وLR−.
  • مقارنة DeLong بين المؤشرات، ومنحنى ROC، وجدول إحداثيات كامل في Excel.
  • أمر ROC في SPSS syntax لإعادة التحليل.
⚠ إذا ظهرت AUC < 0.5 فالقيم الأقل هي المنبئة — غيّر direction إلى "lower" بدلاً من عكس القيمة يدوياً. وانتبه عندما يقل عدد الحالات الموجبة عن 30 لأن فترات الثقة تصبح واسعة.

8. حجم العينة والأدوات الإضافية

الأسهل: /sample-size مع وصف الدراسة. أو مباشرة:

التصميمالأمر
نسبة واحدة (مسح مقطعي)sample_size.py proportion --p 0.5 --margin 0.05 --population 1200 --nonresponse 0.1
مقارنة نسبتينsample_size.py two-proportions --p1 0.30 --p2 0.45 --power 0.8
مقارنة متوسطينsample_size.py two-means --sd 10 --diff 4
معامل ارتباطsample_size.py correlation --r 0.25
انحدار لوجستي (EPV)sample_size.py logistic --predictors 8 --event-rate 0.3

كل الأوامر تبدأ بـ python3 assistant/engine/. مثال على المخرجات:

Cochran n0 = 384.1
Finite population correction (N=1200) → n = 291.2
Final sample (non-response 10%) = 324

ومعه فقرة Methods جاهزة للنسخ.

أدوات أخرى في stats_core.py

  • Cohen's Kappa + PABAK لاتفاق مقيّمَين مع تصنيف Landis & Koch — اطلب: «احسب كابا بين العمودين rater1 و rater2».
  • ألفا كرونباخ لأي مجموعة بنود مع α عند حذف كل بند.

المراجع السريعة

  • assistant/knowledge/reporting_standards.md — قوالب صياغة كل اختبار وعتبات حجم الأثر.
  • assistant/knowledge/test_selection.md — جدول اختيار الاختبار حسب نوع المتغير.

10. الخصوصية، النصائح وحل المشكلات

الخصوصية

  • المجلدان assistant/clients/ وassistant/output/ مستبعدان من git — لا تُرفع بيانات المشاركين أبداً.
  • احذف المعرّفات الشخصية واستبدلها بأرقام تسلسلية قبل التحليل.
  • لا تنقل البيانات الحقيقية إلى مجلد examples/.

نصائح لأفضل نتيجة

  • أرفق الاستبيان دائماً مع البيانات — يحسّن تحديد المحاور والبنود العكسية.
  • اذكر أهداف الدراسة — ليختار المتغير التابع والمنبئات بشكل صحيح.
  • راجع الخطة التي يعرضها قبل الموافقة، خاصة نقاط القطع والفئات المرجعية.
  • استخدم ملف *_syntax.sps للتحقق من النتائج في SPSS قبل التسليم للعميل.
