# متجر رواج — متجر دروبشيبنغ عربي (RTL)

متجر إلكتروني خفيف بدون خادم (HTML + CSS + JavaScript) موجّه لسوق عُمان والخليج، يستقبل الطلبات عبر **واتساب** مع **الدفع عند الاستلام**.

## المميزات
- واجهة عربية كاملة (RTL) متجاوبة مع الجوال
- تصنيفات وبحث فوري للمنتجات
- نافذة تفاصيل المنتج مع نسبة الخصم
- سلة مشتريات محفوظة في المتصفح + شريط "الشحن المجاني"
- إتمام الطلب برسالة واتساب جاهزة (المنتجات، الإجمالي، العنوان، طريقة الدفع)
- **حاسبة أرباح** (`profit.html`): صافي الربح لكل طلب، الهامش، ROAS للتعادل، والسعر المقترح مع احتساب الطلبات المرفوضة في COD

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو:
```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## ⚠ قبل الإطلاق
ضع رقم واتساب الحقيقي في `STORE_CONFIG.whatsapp` داخل `js/products.js`. ما دام الرقم هو القيمة التجريبية `96890000000` فإن المتجر **يرفض إرسال الطلبات** ويعرض تنبيهاً، حتى لا تضيع طلبات حقيقية.

اختبار مسار الطلب: `node tests/store_checkout.test.js`

## التخصيص
كل التعديلات في ملف واحد: `js/products.js`
- `STORE_CONFIG`: اسم المتجر، رقم واتساب، العملة، رسوم الشحن، حد الشحن المجاني
- `PRODUCTS`: المنتجات (السعر، السعر القديم، تكلفة المورد `cost`، التصنيف…)

> الأيقونات الحالية رموز تعبيرية مؤقتة؛ استبدلها بصور المنتجات الحقيقية من المورد.
